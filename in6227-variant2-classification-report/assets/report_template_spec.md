# IN6227 Reports Template — Fallback Specification

Source: supplied `IN6227-Reports-Template.doc`.

## Main structure

Use these main headings, in this order:

1. INTRODUCTION
2. METHODS OR PROCEDURES
3. RESULTS
4. DISCUSSION
5. CONCLUSION
6. REFERENCES

The supplied template uses Times New Roman 10-point body text, a **single-column page layout**, and instructs authors not to alter font sizes or line spacing merely to squeeze content into a page limit. Tables/figures should be placed within the text rather than appended after references.

## Variant 2 adaptation

Preserve the main headings above. Place numbered workflow sub-steps under `METHODS OR PROCEDURES`. Add the assignment-required model/runtime metadata without creating a new competing heading hierarchy.

## Rendering safety

The rendered report must remain within the template margins and **must stay single-column**. It must not contain overlapping text, clipped text, or table overflow.

Prefer naturally wrapping prose. Avoid long unbroken code/parameter strings in narrow columns. Use compact tables for long hyperparameter sets. Do not use manual paragraph line breaks, floating text boxes, positioned text, or multi-column CSS to force layout.
